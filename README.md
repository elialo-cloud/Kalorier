# Kalorier

En snabb och exakt svensk kaloriräknare.

## Mål
- Ange mat i gram eller stycken
- Hantera ätbar mängd, rå/tillagad vikt och portioner
- Räkna kcal, protein, kolhydrater och fett exakt
- Bygga en bra svensk matdatabas
- Recept med automatisk näringsberäkning
- Ingen AI krävs för själva kaloriberäkningen

## Planerad stack
- Cloudflare Workers + Workers Static Assets
- Cloudflare D1 för mat- och användardata
- TypeScript
- GitHub för versionshantering och utveckling

## Datakällor
- Livsmedelsverket som primär källa för svenska livsmedel
- Open Food Facts för streckkoder och färdiga produkter
